# Зелёная тарелка — приложение для здорового питания

Адаптивное PWA-приложение для iPhone, Android и компьютера.

## Что уже работает
- Подборка рецептов по категориям: завтрак, обед, ужин, перекус.
- Карточки рецептов с ингредиентами, приготовлением и примерными КБЖУ.
- Дневник питания с суммированием калорий и БЖУ.
- Настройка дневной цели калорий.
- Загрузка фотографии еды и анализ блюда через OpenAI Responses API (при подключённом ключе).
- Сохранение дневника и цели на устройстве.
- Установка как PWA и базовый офлайн-кэш интерфейса.

## Запуск на компьютере
Нужен Node.js 18+.

```bash
npm install
```

Скопируйте `.env.example` в `.env` и вставьте свой API-ключ:
```env
OPENAI_API_KEY=ваш_ключ
OPENAI_MODEL=gpt-6.2-astra
PORT=3000
```

Затем:
```bash
npm start
```
Откройте http://localhost:3000

**Важно:** API-ключ хранится только на сервере в `.env`, не вставляйте его в `public/app.js` и не публикуйте `.env`.

## Установка на iPhone
Для установки нужен опубликованный HTTPS-адрес:
1. Разместите приложение на хостинге, который поддерживает Node.js (например, Render или Railway).
2. Добавьте `OPENAI_API_KEY` в переменные окружения сервиса.
3. Откройте HTTPS-ссылку в Safari.
4. Нажмите «Поделиться» → «На экран Домой» → «Добавить».

## Установка на Android
Откройте HTTPS-ссылку в Chrome и выберите «Установить приложение» или «Добавить на главный экран».

## Фото-анализ
Сервер передаёт изображение модели с поддержкой vision через OpenAI Responses API. Для анализа нужен действующий API-ключ и доступ к API; использование API может тарифицироваться отдельно. Оценка калорий по фотографии приблизительна: модель не может точно определить вес, масло, соусы и скрытые ингредиенты.

## Данные и безопасность
Дневник и дневная цель хранятся локально в браузере устройства. Фото отправляется на ваш сервер для анализа; сервер передаёт его в API. Перед публичным запуском добавьте политику конфиденциальности, лимиты запросов и защиту от злоупотреблений.
